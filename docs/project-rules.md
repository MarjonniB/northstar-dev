# Project Rules

Northstar Dev is a learning-first project. The application can remain visually simple while the workflow and fundamentals improve.

## Core rules

- Do not work directly on `main`.
- Use one ticket per branch when practical.
- Keep no more than two tickets in progress at once.
- Prefer learning a fundamental over polishing appearance.
- Test changes before marking work complete.
- Use pull requests for meaningful changes.

## AI assistance

Use AI as a mentor, reviewer, debugger, and teacher before using it as a code generator.

Preferred help order:

1. Hint
2. Explanation
3. Pseudocode
4. Partial example
5. Full solution after an attempt

## Definition of Done

A ticket is complete when its acceptance criteria are met, the change is tested, there are no obvious console errors, the work is committed and pushed, and any required pull request is merged.
